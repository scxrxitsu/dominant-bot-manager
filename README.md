# Dominant Bot Manager

Desktop-приложение на Electron для управления несколькими Minecraft-аккаунтами (ботами) одновременно. Каждый аккаунт подключается к серверу как отдельный клиент (через mineflayer), со своим ником, чатом и, при необходимости, своим прокси.

## Возможности

- Произвольное количество аккаунтов (по умолчанию 3, можно добавлять и удалять кнопками в интерфейсе)
- Подключение к серверу: хост, порт, версия, тип входа (Offline / Microsoft)
- Прокси на каждый аккаунт отдельно: SOCKS5, SOCKS4 или HTTP, с логином/паролем при необходимости, и проверкой внешнего IP через прокси
- Чат: сообщение можно отправить от конкретного аккаунта или сразу от всех подключённых
- Макросы: до 20 своих команд/сообщений на каждый аккаунт + 20 общих. Левый клик отправляет, правый — назначает команду
- Конвой: аккаунты могут следовать друг за другом паровозиком за указанным игроком (через mineflayer-pathfinder)
- Проверка сервера (пинг, версия, количество игроков) без входа в аккаунт
- Цветной чат с поддержкой форматирования сервера, кликабельные ссылки, копирование сообщения по правому клику
- Все настройки (ники, хост, прокси, макросы) сохраняются локально и восстанавливаются при следующем запуске

## Требования

- Node.js 18 или новее
- Windows (сборка `.exe` настроена под Windows; на других ОС приложение можно запускать через `npm start`, но сборка не проверялась)

## Установка

```
npm install
```

## Запуск в режиме разработки

```
npm start
```

## Сборка установочного файла

```
npm run dist
```

Результат появится в папке `dist`: `Dominant Bot Manager Setup <версия>.exe` (установщик) и `Dominant Bot Manager <версия>.exe` (портативная версия, без установки).

## Структура проекта

- `main.js` — главный процесс Electron: окно, IPC, хранение настроек в userData
- `preload.js` — мост между главным процессом и интерфейсом
- `src/botManager.js` — логика подключения ботов (mineflayer), чат, прокси, следование
- `src/proxy.js` — установка соединения через прокси и проверка внешнего IP
- `renderer/` — интерфейс приложения (HTML/CSS/JS)
- `scripts/make-icon.js` — генерация иконки приложения

## Важно

Приложение подключается к серверам через сторонние клиентские библиотеки (mineflayer), а не через официальный клиент Minecraft. Используйте его только для своих аккаунтов и на серверах, где это разрешено правилами сервера. Обход античит- или антибот-систем сервера не поддерживается и не является целью проекта.
